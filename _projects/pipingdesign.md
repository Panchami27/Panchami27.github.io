## Overview

- pipingdesign.py code is written to calculate pipe size.
- Input data is the fluid type, flow rate, inlet and outlet pressure, temperature of fluid, viscosity of fluid, and type of connections.
- The output of the code gives the total pressure in the pipeline and the desired nominal diameter of the pipe.
- Data used in code taken from Example 5.2 from Introduction to Process Engineering and Design by S B Thakore and B I Bhatt, McGraw Hill, 2nd Edition, 2015.
